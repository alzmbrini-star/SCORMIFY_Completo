# SCORMIFY maintenance

## Keep the Creator Tutor current

For every user-facing feature or behavior change, review and update the relevant
entries in `backend/services/creator_guide.py` in the same delivery. Include the
actual entry point, supported behavior, permissions, prerequisites, credit usage
and export limitations when applicable. Do not describe planned functionality as
already available. Reuse verified routes for navigation links, preserve role
restrictions, and run the relevant Creator Tutor guide tests before publishing.

The user explicitly requests that the Tutor always learn about new features.
