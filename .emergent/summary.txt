**Code Architecture**


**Key Technical Concepts**
-   **Async API with Polling**: Used to manage long-running AI generation tasks, preventing HTTP timeouts by returning a task ID immediately and allowing the client to poll for the result.
-   **Persistent State Management**: Shifted the async task queue from an in-memory Python dictionary to a MongoDB collection to ensure state is shared and durable across a multi-worker production environment.
-   **Base64 Image Persistence**: Implemented a flow to decode base64 image strings from the frontend, save them as files in persistent storage (MongoDB), and replace the temporary data URL with a permanent asset URL.
-   **AI-Driven Content Architecture**: Engineered prompts for Gemini to generate complex, structured JSON representing a decision tree, which is then parsed and stored in the database.
