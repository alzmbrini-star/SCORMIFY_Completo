**Key Technical Concepts**
-   **Production Hardening**: Implementing fixes specifically for a containerized production environment, such as making startup tasks non-blocking, adding DB timeouts, and handling ephemeral filesystems.
-   **Asset Persistence**: Storing binary files (like MP3s) in MongoDB GridFS or as BSON binary data to ensure they persist across container restarts.
-   **Asynchronous Tasks**: Converting long-running, synchronous API calls into background tasks with a polling mechanism on the frontend to prevent gateway timeouts and improve UX.
-   **Role-Based Access Control (RBAC)**: The concept of restricting feature access based on user roles and company-level permissions, now being implemented.
-   **Conditional Rendering**: Using data attributes (e.g., presence of a slide background image) to dynamically change the UI, as seen in the SCORM navigation bar.
