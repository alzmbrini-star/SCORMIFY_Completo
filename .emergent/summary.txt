**what currently exists?**
Um aplicativo web full-stack (React + FastAPI) que converte PPTX em imagens e as empacota em um formato SCORM 1.2. O sistema possui um editor avançado que permite aos usuários adicionar e sincronizar diversos tipos de elementos sobre os slides.

O editor suporta upload de imagens (com compressão automática), vídeos (YouTube, Vimeo, locais), áudio, botões com links, snippets de HTML e Flipbooks. Possui integração com a HeyGen para gerar vídeos de avatares com IA, incluindo geração de roteiro e suporte a fundo transparente (com fallback automático).

A interface do editor inclui uma timeline visual para sincronização de elementos (incluindo redimensionamento de clipes de áudio), uma aba de Layers com reordenação por drag-and-drop, e funcionalidades de CRUD de slides.

O pacote SCORM exportado inclui um player com menu de navegação, controle de volume, autoplay de vídeos, e uma overlay para solicitar a rotação do dispositivo em modo mobile (atualmente com bugs). A aplicação foi personalizada com o logo do cliente.
